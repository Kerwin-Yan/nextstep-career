# 下一程 · 求职工作台

用于管理求职准备任务、岗位、投递进展、简历与面试复盘的网页 PWA。

- 桌面与移动端共用同一网址，支持添加到手机主屏幕。
- 求职记录和简历附件只保存在各自浏览器/设备的 IndexedDB 中。
- 不提供云端同步或招聘平台自动接入。
- 首次使用建议先添加到主屏幕，再录入数据；清理浏览器或更换域名前请先导出备份。
- 本仓库仅包含通用网页程序，不包含个人求职记录、简历文件或项目背景材料。

本地预览：在此目录运行 `python3 -m http.server 4335` 后访问 http://127.0.0.1:4335/ 。

GitHub Pages 发布 main 分支根目录。
